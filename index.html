💡 Challenges & Solutions

Real Problems, Real Engineering

Key technical decisions made during development.

01
Semantic Matching Without Keyword Dependency
Problem

Traditional platforms match by keywords, missing contextual relevance — "developer" and "software engineer" are the same role but would never match.

Solution

Delegated semantic analysis to Cohere's multilingual embedding API pgvector is included in the schema as a migration path to decouple from API dependency at scale.

Context-aware matching
02
Multi-Language NLP Support
Problem

Argentina's job market requires Spanish-English bilingual understanding that most models handle poorly.

Solution

Chose Cohere's multilingual model over OpenAI for superior Spanish context and 5× lower cost

5× cost reduction
03
Secure CV File Handling
Problem

Users upload CVs containing sensitive personal data that must not be publicly accessible.

Solution

Implemented RBAC + signed URLs with 1-hour expiration — only authorized roles can access each file.

Zero unauthorized access
